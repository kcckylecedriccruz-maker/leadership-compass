# 2-minute demo script

**Owners:** Kyle Cedric Cruz and Vivian Cruz

Audience: course graders. Narration: English, read word for word (about 280 words, a calm 2 minutes).
Record with Snipping Tool (Win + Shift + R, microphone on) or Xbox Game Bar (Win + G) at
https://leadership-compass.leadership-compass.workers.dev. Use test data only, never real staff feedback.

## Before you press Record

Open these as browser tabs, in this order, signed in as admin, zoom 100–110%:

1. **Workspace → Org structure** (the chart visible).
2. **Workspace → Cycles**, with the open cycle's **Review status** expanded.
3. **My assessments → an open form** scrolled to the first item (a draft, not submitted).
4. **Workspace → Dashboard → a person's report**, with **AI summary** and **How to improve** already generated
   (generate them before recording so you never wait on the AI on camera).
5. **Workspace → Insights → Ask a question**, with a question typed but not sent, e.g. *"Which competency is lowest
   across the cycle?"*
6. **GitHub → Actions** tab of the repository, showing green runs.

Also: close other tabs, turn on Windows Do Not Disturb, and do one dry run.

## Script

| Time | Do this | Say this |
| --- | --- | --- |
| 0:00–0:15 | Tab 1: Org structure | "This is Leadership Compass, an AI-powered app for leadership 360 reviews. Organisations know these reviews matter, but they rarely run them: setup is tedious, raters struggle with the questions, and turning comments into development plans takes days." |
| 0:15–0:30 | Tab 1, then Tab 2: Cycles → Review status | "Here the org chart decides who evaluates whom: self, manager, skip-level, direct reports, peers and even external clients. When I open a cycle, every evaluation is created automatically, and I can see who has finished and who is still pending." |
| 0:30–1:00 | Tab 3: the form. Click **Help me understand**, switch to **Filipino**, ask a short question. Click **Suggest behaviours**. Type a vague note like *"Good leader"* and click **Improve with AI**. | "This is where AI helps the rater. If a question is unclear, they can ask about it in English or Filipino. Suggest behaviours gives examples of what to look for. And if a note is vague, like 'good leader', the note coach suggests a specific, observable example. The AI can suggest a rating, but the rater always decides." |
| 1:00–1:30 | Tab 4: the report. Show the scores briefly, open **AI summary**, then **How to improve**; point at a manager note and the **Release** button. | "For administrators, results are grouped by rater, with anonymity rules for small groups. AI summarises all the feedback into strengths, development areas and a 30, 60, 90-day plan. How to improve suggests interventions for each focus area. The manager reviews the plan and adds notes before it is released to the employee. Names are removed before anything is sent to the AI." |
| 1:30–1:45 | Click the **bell** and one item (it jumps and highlights). Then Tab 5: send the question. | "The notification bell shows what needs action and takes you straight to it. Admins can also ask questions about the scores in plain English." |
| 1:45–1:55 | Workspace → **Monitoring** | "Monitoring shows page views, errors and AI usage, with no personal data, and an uptime check runs every six hours." |
| 1:55–2:05 | Tab 6: GitHub Actions | "Every push runs lint, type checks, unit tests and a production build on GitHub Actions. Thank you for watching." |

## If something goes wrong while recording

- **The AI is slow or busy:** say "the free AI service is busy, so here is one I generated earlier" and move on to a
  tab that already has a result. Don't wait on camera.
- **You stumble over a line:** pause for two seconds and say the line again; cut the pause later, or simply record
  again. Two-part recordings are fine.
- **Running long:** skip the Insights question (Tab 5); it is the least important part.
