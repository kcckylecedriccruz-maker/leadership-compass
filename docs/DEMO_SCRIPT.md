# 2-minute demo script

Record your screen (e.g. Windows Game Bar: Win + G, or OBS) at https://leadership-compass-formidea.netlify.app.
Use test data, not real staff feedback.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:15 | Sign-in page | "Leadership Compass helps HR teams run leadership 360 reviews. The problem: spreadsheets, confused raters and vague comments." |
| 0:15–0:35 | Workspace → Org structure, then Cycles → a cycle's Review status | "Evaluations come from the org chart — self, manager, skip-level, peers and external raters — and I can see who is done or pending." |
| 0:35–1:10 | My assessments → open a form → **Help me understand** (switch to Filipino), **Suggest behaviours**, type a short note → **Improve with AI** → **Suggest a rating from my note** | "This is the AI part for raters: it explains the question in English or Filipino, suggests observable behaviours, improves vague notes, and suggests a rating — but the rater decides." |
| 1:10–1:40 | A report → **AI summary** → Generate | "For admins, AI turns all the feedback into strengths, development areas and a 30/60/90-day plan. Names are removed before anything is sent to the AI." |
| 1:40–1:55 | Workspace → Insights → Ask a question; then Monitoring | "Admins can ask questions about the scores and compare cycles. Monitoring shows usage and errors." |
| 1:55–2:00 | GitHub repo → Actions tab | "Every push runs lint, type checks, tests and build. Thanks for watching." |

Tips: do one dry run first so the AI answers are already cached in your mind; keep the browser zoom at 100–110%.
